Anti-fraud

Four checks, one honest result.

Each scan passes four independent checks so a single weak point can't be exploited. Suspicious cases are logged for a person to review, never auto-blocked.

One phone per account

Each account is tied to the phone it first signed in on. A new device is logged for the lecturer, not trusted automatically.

Inside the room only

A scan is accepted only when GPS places the phone in the classroom. Readings too weak to trust are rejected outright.

Only while live

The code works only between Start and End. A code grabbed early or late simply won't count.

No scanning for friends

If one phone marks several students, it's logged for review, catching anyone signing in for absent classmates.

How it works

How a class runs.

Four steps, start to finish: the only sequence the system cares about.

01

Start

The lecturer opens the course and taps Start. The phone captures the room location and the QR appears on screen.

02

Scan

Students in the room open the scanner and read the code from the screen or wall.

03

Present

A valid scan returns a single word: Present. Each student is marked once, no duplicates.

04

End

The lecturer taps End. Everyone enrolled who didn't scan is marked absent for that class.
